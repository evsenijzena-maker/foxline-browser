# Foxline Browser

Современный многовкладочный браузер для Windows 10/11 на **Electron + Chromium**.

## Возможности
- Вкладки: создание/закрытие, переключение.
- Адресная строка: URL или поиск через Google.
- Навигация: назад, вперёд, обновить, домой.
- Внутренние страницы: Домашняя, Закладки, История, Загрузки, Настройки, О браузере.
- Закладки и история посещений (локальное хранение в `userData`).
- Загрузки файлов с отображением прогресса/состояния.
- Режим инкогнито (отдельное окно; история не сохраняется).
- Несколько окон.
- Светлая/тёмная тема, настраиваемая стартовая страница и плитки быстрого доступа.
- Регистрация обработчика `http/https` (назначение браузером по умолчанию завершается в параметрах Windows).
- Безопасная архитектура: `contextIsolation: true`, `nodeIntegration: false`, `sandbox`/IPC-мост через preload, `webSecurity: true`.

## Структура проекта
```text
Foxline/
  assets/            # логотип и ресурсы
  build/             # иконки для electron-builder (icon.ico/png)
  src/
    main/            # главный процесс Electron
    preload/         # безопасный IPC-мост
    renderer/        # UI: HTML/CSS/JS, внутренние страницы
  package.json
```

## Требования
- Node.js 18+ (проверено с Node 24)
- npm
- Windows 10/11 для сборки `.exe`/установщика

## Установка зависимостей
```powershell
cd "C:\Users\Admin\OneDrive\Рабочий стол\Foxline"
npm install
```

## Запуск в режиме разработки
```powershell
npm run dev
```

## Сборка Windows
Создать установщик (NSIS):
```powershell
npm run dist
```

Результаты будут в папке `dist/`:
- `Foxline Setup.exe` — установщик (NSIS).
- установленное приложение содержит исполняемый файл `Foxline.exe`.
- установщик позволяет выбрать папку установки, создаёт ярлык на рабочем столе и пункт меню Пуск, поддерживает удаление через Windows.

Дополнительно (распакованная сборка для проверки):
```powershell
npm run pack
```

## Горячие клавиши
- `Ctrl+T` — новая вкладка
- `Ctrl+W` — закрыть вкладку
- `Ctrl+L` — фокус адресной строки
- `Ctrl+R` — обновить
- `Ctrl+N` — новое окно
- `Ctrl+Shift+N` — новое окно инкогнито

## Примечания
- Веб-страницы отображаются через `<webview>` (Chromium) внутри UI браузера; это обеспечивает реальную многовкладочную навигацию.
- Назначение браузером по умолчанию в Windows 10/11 обычно требует подтверждения пользователя в «Параметры → Приложения → Приложения по умолчанию»; Foxline регистрирует обработчики `http/https`.
- Перед релизом рекомендуется проверить открытие популярных сайтов, загрузки, закладки/историю и работу на целевой машине.
