# Автообновление Foxline через GitHub Releases

## 1. Настройте репозиторий
1. Создайте репозиторий на GitHub (например `foxline-browser`), публичный или приватный.
2. В `package.json` замените:
   - `YOUR_GITHUB_USERNAME` на ваш GitHub username/организацию
   - `repo` на имя репозитория, если другое
3. Для приватного репозитория нужен GitHub token (см. п. 4).

## 2. Подготовьте релиз
1. Поднимите версию в `package.json`, например `1.0.0` -> `1.0.1`.
2. Обновите текст в `src/renderer/scripts\app.js` (страница «Что нового»), если нужно.
3. Соберите релиз из `C:\Foxline`:
   ```powershell
   cd C:\Foxline
   $env:GH_TOKEN="ваш_github_token"   # для публикации/приватного репо
   npm run dist -- --publish always
   ```
   Или соберите локально и загрузите файлы вручную:
   ```powershell
   cd C:\Foxline
   npm run dist
   ```

## 3. Что загрузить в GitHub Release
Для автообновления Windows (NSIS) в релизе должны быть:
- `Foxline Setup.exe`
- `Foxline Setup.exe.blockmap`
- `latest.yml`

Файлы находятся в `C:\Foxline\dist\` после сборки.

## 4. Токен (GH_TOKEN)
- Нужен для `--publish always` и для доступа к приватному репозиторию.
- GitHub → Settings → Developer settings → Personal access tokens.
- Для публичного репозитория ручная загрузка файлов в Release обычно работает без токена в приложении; для приватного обновления потребуется отдельная схема/токен — проще использовать публичный репозиторий обновлений.

## 5. Важные правила
- Тег релиза должен соответствовать версии (обычно `v1.0.1`).
- `latest.yml` должен соответствовать загруженному `Foxline Setup.exe`.
- У пользователей должна быть **установленная** версия Foxline (из Setup). Портативная/dev не обновляется автоматически.
- Установленное приложение проверяет обновления при запуске и каждые 15 минут, скачивает автоматически, устанавливает при перезапуске/выходе или по кнопке в «Что нового».

## 6. Быстрая проверка
1. Установите версию `1.0.0`.
2. Опубликуйте релиз `1.0.1` с `latest.yml` + `Foxline Setup.exe`.
3. Запустите установленный Foxline и откройте «Что нового» — должен появиться статус загрузки/готовности обновления.
